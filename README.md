# DOT: MotionCalm

Приложение «Против укачивания» (MotionCalm). Точки по краям экрана смещаются при разгоне,
торможении и поворотах, поэтому глаза получают понятный ориентир движения. Исходники лежат в папке `MotionCalm/`.

## Версии и номера сборок

- Версия и номер сборки задаются в `MotionCalm/version.properties`:
  `versionName` (например, `1.1`) и `versionCode` (номер сборки: целое число).
- При каждом изменении, которое уходит в релиз, увеличивайте `versionCode` (следующий будет `3`).
  CI не опубликует сборку с номером, который уже выпущен.
- Журнал изменений ведётся в `MotionCalm/CHANGELOG.md`. Раздел текущей сборки становится описанием релиза.

## Автосборка и релизы

Workflow `.github/workflows/android-build.yml` запускается при каждом push в `main` и `arena/**`,
если менялась папка `MotionCalm/`. Он:

1. проверяет, что номер сборки новый;
2. запускает unit-тесты и lint;
3. собирает APK, подписанный ключом из репозитория;
4. проверяет подпись (отпечаток из `MotionCalm/release-cert-sha256.txt`) и `versionCode` внутри APK;
5. публикует релиз с тегом `v1.1-build2` и файлом `MotionCalm-1.1-build2.apk`.

Если сборка с тем же номером уже опубликована для того же кода (например, после слияния в `main`),
публикация пропускается. Если код другой, запуск падает с ошибкой, и номер нужно увеличить.

## Обновления в приложении

- Кнопка «Проверить обновления на GitHub» на главном экране находит самую новую сборку среди релизов,
  скачивает APK и предлагает установить.
- Установку подтверждает пользователь в системном окне Android. При первом обновлении Android попросит
  разрешить установку из этого приложения.
- Android принимает обновление только если APK подписан тем же ключом, что и установленная версия.

## Ключ подписи

- APK подписывается ключом `.android/debug.keystore` из этого репозитория (алиас `androiddebugkey`).
  Это тот же ключ, которым подписан `MotionCalm-debug.apk`.
- Ключ публичный: он лежит в открытом репозитории. Подписать APK им может любой, и телефон примет такой APK
  как обновление, если его установить поверх приложения. Для личного приложения это приемлемый риск, но он есть.
- Публичный отпечаток, который проверяет CI: `MotionCalm/release-cert-sha256.txt`. CI не публикует APK с другим ключом.
- Не меняйте и не удаляйте `.android/debug.keystore`: тогда обновления перестанут устанавливаться поверх уже установленной версии.
- Чтобы позже перейти на закрытый ключ, понадобится один раз удалить приложение с телефона и поставить новую версию.

## Локальные проверки

- Физика точек: `physics-test/PhysicsTest.java`. Запуск из `MotionCalm/` (нужен JDK 17+):
  `javac -encoding UTF-8 -d build/physics app/src/main/java/com/example/motioncalm/DotPhysics.java physics-test/PhysicsTest.java`
  и затем `java -cp build/physics PhysicsTest`.
- Сборка на своём компьютере: Android Studio или `./gradlew assembleDebug` в `MotionCalm/`.
  Нужен Android SDK; `local.properties` создаётся локально и в git не хранится.
